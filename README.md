# mia-tracker

Страница трекера закрывающих документов. Данные зашифрованы, доступ по паролю.

Сайт: https://dgo-ly.github.io/mia-tracker/

Интерфейс сохранён. Программа ежедневной проверки читает таблицы
директоров и готовит зашифрованный отчёт. После сверки комментариев
и статусов подтверждённые изменения можно опубликовать.
Бухгалтерские суммы остаются на дате последней загруженной сверки 1С.
Для нового бухгалтерского периода нужны новые исходные отчёты.

Источники читаются через Google Drive и Google Sheets. Для ежедневного
запуска нужен планировщик и доступ к таблицам. Проверенное обновление
публикуется через GitHub с проверкой текущей версии.

- [Порядок обновления](docs/UPDATE_GUIDE.md)
- [Источники и чтение таблиц](docs/SOURCES.md)

В Git хранятся интерфейс, код, синтетические тесты и зашифрованные данные.
Пароль, исходные выгрузки, открытые снимки и отчёты с суммами сюда не добавляются.
